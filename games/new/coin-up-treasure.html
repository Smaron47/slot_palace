📜 Paytable

Wins read left → right on any active payline. Three or more matching symbols required. Wilds substitute for any regular gem symbol.

Coin fills the Coin Meter (+1 point). When full → Treasure Chest Bonus.
Coin Upgrade raises your coin value level (×1 → ×2 → ×3 → ×5 → ×10).
Key adds a key toward unlocking the chest (3 keys required).
Treasure Chest activates the bonus when the meter is full OR when all keys are collected AND a chest symbol lands.

❓ How To Play

1. Set your bet with the + / − buttons.

2. Press SPIN or the SPACE key. Use AUTO for up to 25 automatic spins.

💰 Coin Collection

Every Gold Coin on the board adds +1 meter point × your coin value level. The coin value level goes up when a Coin Upgrade symbol lands (Lv1 ×1 → Lv2 ×2 → Lv3 ×3 → Lv4 ×5 → Lv5 ×10).

🔑 Keys & Chest

Keys are collected across spins. Once you have 3 keys, the next Treasure Chest symbol triggers the bonus. Keys reset after the bonus.

🎁 Treasure Bonus

When the Coin Meter fills OR the key-required Treasure Chest triggers, you pick one of three chests. Each chest holds a random virtual-credit reward (25 / 50 / 100 / 250 credits, weighted). Rewards are added to your balance.

🌪️ Wild

Wilds substitute for any regular gem symbol (Ruby, Emerald, Crown, Idol, Seven), but never for Coin, Upgrade, Key, or Chest symbols.
